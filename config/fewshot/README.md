# Few-shot examples (cloud copy)

(`VISION_FEWSHOT_DIR=/app/config/fewshot`, set in the Dockerfile). Copies of
`reference/fewshot/` with staff names and a clerk's ID number blacked out; the patient details on
the samples were already replaced by the organizers. Keep `examples.json` in step with the local
set when it changes.
